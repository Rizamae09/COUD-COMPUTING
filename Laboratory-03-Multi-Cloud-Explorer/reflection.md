# Checkpoint 8 – Mission Reflection

## Mission Reflection

Throughout this mission, the cloud platform that impressed me the most was **Amazon Web Services (AWS)**. I liked that AWS offers many services for computing, storage, networking, databases, security, and application development. I also learned that AWS can support different organizations, from small startups to large companies. Its flexibility and scalability allow businesses to increase or decrease resources depending on their needs.

While studying **AWS, Microsoft Azure, and Google Cloud Platform (GCP)**, I learned that all three platforms provide similar services, including computing, storage, databases, networking, security, and identity management. However, each platform has different strengths. AWS offers many cloud services, Azure has strong integration with Microsoft technologies, and GCP is known for its AI, machine learning, data analytics, and Kubernetes services.

One important lesson I learned is that **business requirements are important when choosing a cloud provider**. Organizations should consider their budget, existing technology, security, performance, scalability, and IT skills. Azure may be better for organizations already using Microsoft products, while GCP can be useful for AI and machine learning projects. AWS can be a good option for organizations that need many services and flexible resources.

Acting as a **Cloud Solutions Consultant** helped me understand that there is no single cloud platform that is best for every organization. The right choice depends on the client's needs, goals, budget, and future plans. The client recommendations helped me apply this knowledge to different situations.

The **Linux server investigation** was also useful. I learned how commands such as `cat /etc/os-release`, `lscpu`, `free -h`, and `df -h` can show information about the operating system, CPU, memory, and disk space. This information is useful when planning a cloud migration.

Overall, this mission improved my understanding of **cloud computing and its real-world applications**. I gained knowledge about AWS, Azure, GCP, Linux servers, and cloud decision-making. It also helped me understand how technical knowledge can be used to choose suitable cloud solutions for different organizations.
