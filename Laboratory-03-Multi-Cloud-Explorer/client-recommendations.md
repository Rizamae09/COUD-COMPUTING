# Cloud Platform Recommendations

## Client A – AI Research Company

### Recommended Platform: Google Cloud Platform (GCP)

Google Cloud is a good option for the company because it focuses on Artificial Intelligence and Machine Learning projects that need powerful computing resources. GCP offers different tools and infrastructure designed for AI and machine learning development. Its data analytics and Kubernetes services can also help support research projects and scalable AI applications.

### Recommended Services

* **Compute Engine** – Provides virtual machines for computing-intensive workloads.
* **Google Kubernetes Engine (GKE)** – Provides a managed Kubernetes platform for running containerized AI applications.
* **Vertex AI** – Provides tools for creating, training, and deploying machine learning models.
* **Cloud Storage** – Provides scalable storage for datasets, models, and research files.

---

## Client B – Global E-Commerce Company

### Recommended Platform: Amazon Web Services (AWS)

AWS is recommended because the company operates in different parts of the world and needs infrastructure that is both scalable and reliable. AWS has multiple Regions and Availability Zones that can help create applications that remain available even when problems occur in one location. It also provides services that can automatically increase computing resources and distribute traffic across servers. These features make AWS a suitable platform for a large global e-commerce business.

### Recommended Services

* **Amazon EC2** – Provides scalable computing resources for web and application servers.
* **Elastic Load Balancing** – Spreads incoming traffic across multiple resources to improve application performance.
* **Amazon EC2 Auto Scaling** – Automatically increases or decreases computing resources depending on workload demand.
* **Amazon RDS** – Provides managed relational databases for storing e-commerce information.
* **Amazon CloudFront** – Helps deliver website content to users through a global content delivery network.

---

## Client C – Startup Company

### Recommended Platform: Amazon Web Services (AWS)

AWS is a good choice for the startup because it offers many cloud services that can help develop and launch a mobile application without requiring physical servers. The company can start with basic resources and increase them as the number of users grows. AWS also has managed services that can lessen the amount of infrastructure work needed by a small development team.

### Recommended Services

* **Amazon EC2** – Provides virtual servers that can be used to run applications and other workloads.
* **Amazon S3** – Provides scalable storage for files, images, backups, and application data.
* **Amazon RDS** – Provides a managed relational database for storing and managing application data.
* **Amazon CloudFront** – Delivers application content to users through a global content delivery network.

---

## Client D – University

### Recommended Platform: Microsoft Azure

Azure is a suitable choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure works well with Microsoft's existing technologies, which can make the migration process and identity management easier. The university can also connect its current on-premises systems to Azure and move workloads gradually instead of transferring everything to the cloud at once.

### Recommended Services

* **Azure Virtual Machines** – Allows Windows Server workloads to run in the cloud.
* **Microsoft Entra ID** – Provides identity and access management through the cloud.
* **Azure SQL Database** – Provides a managed SQL database for storing university data.
* **Azure Virtual Network** – Provides networking between Azure resources and the university's existing infrastructure.
