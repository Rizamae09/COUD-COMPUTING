## 1. Which cloud provider offers the broadest range of services?

AWS offers a very wide selection of cloud services compared to the other major cloud providers. It has services for computing, storage, databases, networking, security, analytics, artificial intelligence, and many other technology needs. Because of this, organizations have many options when building their cloud systems.

## 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure has the strongest integration with Microsoft technologies. It works well with products such as Windows Server, Microsoft 365, Microsoft Entra ID, SQL Server, and other Microsoft services. This makes Azure a good option for organizations that already depend on Microsoft products.

## 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is especially strong in **Artificial Intelligence, Machine Learning, and Kubernetes**. It provides different AI and machine learning tools and services, along with **Google Kubernetes Engine (GKE)**, which is a managed platform for running and managing containerized applications.

## 4. Which cloud platform would you personally choose and why?

I would personally choose **Amazon Web Services (AWS)** because it offers a large number of services and gives organizations many choices when building and scaling applications. AWS also has a large global infrastructure, which makes it useful for different types of projects. I think it would be a good choice for both small projects and larger systems because resources can be adjusted depending on the needs of the organization.
