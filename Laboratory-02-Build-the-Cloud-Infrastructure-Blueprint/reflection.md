# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think compute resources are one of the most important components of cloud infrastructure because they provide the processing power needed to run applications and services. Without compute resources, cloud applications would not be able to process tasks or respond to users.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a reliable and flexible operating system for cloud servers. It manages resources such as CPU, memory, storage, and networking while allowing applications and services to run.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it records how the infrastructure is designed and how its components work together. It helps users and administrators understand the system, troubleshoot problems, and make future changes.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux cloud server using basic Linux commands. I also learned how to identify compute, storage, networking, and operating system resources. In addition, I practiced comparing cloud providers, creating a basic cloud architecture, and documenting technical information using Markdown.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio improved because I added a structured cloud infrastructure project containing technical documentation, a cloud provider comparison, server investigation results, and a cloud architecture diagram. This demonstrates my understanding of basic cloud computing concepts.

## Overall Reflection

Overall, this laboratory activity helped me understand how different cloud infrastructure components work together. I learned that a simple cloud system can connect a user to the Internet, a cloud server, and storage. The activity also helped me become more familiar with Linux, cloud computing, Markdown, and GitHub.
