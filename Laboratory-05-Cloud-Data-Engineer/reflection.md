# Mission Reflection

**1. Why is object storage better suited for storing millions of photos compared to a traditional block storage hard drive?**

Object storage is better for storing millions of photos because it is designed for large amounts of unstructured data. It can store images, videos, and backups, and it can handle a large amount of data as it grows.

**2. How did using Docker make it easier to deploy the MinIO storage server?**

Docker made it easier because I only needed to use one Docker command to download and start the MinIO server. I did not need to install everything manually. I also used the command to set the ports and login credentials.

**3. What is a "bucket" in the context of cloud storage?**

A bucket is a storage container where files or objects are stored. In this activity, I created a bucket named `client-photos` and uploaded a sample file into it.

**4. How do you think large enterprise companies ensure their object storage data is not lost if the physical server crashes?**

Large companies can keep backup copies of their data in different servers or locations. This helps protect the data and allows them to recover it if a physical server crashes.

**5. How is your confidence in navigating the Linux command line growing?**

My confidence in using the Linux command line is slowly growing. At first, I was not very comfortable using commands, but after using Docker commands and checking the running container, I became more familiar with the terminal. I still need more practice, but this activity helped me understand Linux, Docker, and cloud storage better.
