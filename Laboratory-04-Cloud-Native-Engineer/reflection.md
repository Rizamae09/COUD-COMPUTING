# Reflection

In this laboratory activity, I learned the difference between Docker containers and Virtual Machines. Docker containers are lightweight and faster to start because they do not need a complete operating system.

I learned that `-p 8080:80` connects the host port 8080 to the Nginx container’s port 80, allowing me to access the web server through `localhost:8080`.

I also learned that `docker rm` completely removes a container, so data stored inside it may be lost without persistent storage.

Containerization helps developers and operations teams work more consistently by using the same application environment. Overall, this activity improved my knowledge of Docker, cloud-native technologies, and GitHub documentation.
